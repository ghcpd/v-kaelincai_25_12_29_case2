## Phase 3: Implement the Fix

### 3.1 Core Fix Implementation
Fix the non-deterministic behavior in `src/customer_segmentation.py`:

**Primary Fix**: Ensure deterministic K-means clustering:
```python
# Set explicit random_state for reproducibility
self.model = KMeans(
    n_clusters=self.n_clusters,
    random_state=42,           # Fixed seed for reproducibility
    n_init=10,                 # Explicit n_init parameter
    max_iter=300
)
```

**Additional Considerations**:
1. **Cluster Label Canonicalization**: K-means assigns arbitrary cluster IDs (0, 1, 2), but their mapping to semantic labels (Low, Regular, High) may vary. Implement logic to canonicalize cluster labels based on cluster centers or feature means to ensure:
   - Cluster 0 = Low-engagement (lowest spending/engagement)
   - Cluster 1 = Regular (medium)
   - Cluster 2 = High-value (highest spending/engagement)

2. **Implementation Strategy**:
   - After K-means fitting, sort clusters by their centroid values
   - Create a mapping from arbitrary K-means labels to canonical labels
   - Apply this mapping consistently in both `fit()` and `predict()` methods

3. **Deterministic Initialization**:
   - Use `random_state=42` (or any fixed integer) in KMeans
   - Set `n_init` explicitly to avoid sklearn version differences
   - Ensure no other sources of randomness in data preprocessing
